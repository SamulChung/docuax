## 3. 기술 분야

본 발명은 대규모 언어 모델(LLM)에 대한 프롬프트 엔지니어링(Prompt Engineering) 분야에 속한다. 구체적으로는 업무 문서 작성 및 AI 보조 작업에서 사용자의 의도를 구조화된 형태로 AI에 전달하기 위한 방법론 및 이를 구현한 소프트웨어 시스템에 관한 것이다.

---

## 4. 배경 기술 및 종래 기술의 문제점

### 4.1 종래 기술

현재 AI 프롬프트 엔지니어링 분야에서는 다음과 같은 방식이 사용되고 있다:

- **자유 형식 프롬프트**: 사용자가 자연어로 지시를 입력. 일관성 없는 결과를 초래하며 전문가 지식 없이는 고품질 출력 획득이 어렵다.
- **Few-shot 예시 기반**: 예시를 제공해 패턴을 유도. 예시 설계에 전문성이 요구되며 재사용성이 낮다.
- **Chain-of-Thought(CoT)**: 단계별 추론을 유도하는 방식. 특정 유형(수학, 논리)에 효과적이나 문서 작성 업무에는 구조적 지원이 부족하다.
- **역할 부여(Role Prompting)**: 단순히 "당신은 전문가입니다"라고 기술. 역할 외 나머지 맥락 요소가 빠져 불완전하다.

### 4.2 종래 기술의 문제점

1. **일관성 부재**: 동일 작업도 프롬프트 작성자에 따라 결과 품질이 크게 달라진다.
2. **재사용 어려움**: 구조화되지 않은 프롬프트는 다른 업무·맥락에 전용하기 어렵다.
3. **한국어 공문서 특화 부재**: 기존 방법론은 영어 중심이며, 한국 행정·기업 문서의 형식·어조·위계 구조를 반영하지 못한다.
4. **작업 유형 구분 없음**: "요약"과 "생성"은 AI에게 요구하는 출력 유형이 근본적으로 다름에도 동일한 방식으로 지시한다.

---

## 5. 발명의 목적

본 발명은 위의 문제점을 해결하기 위해 다음을 목적으로 한다:

1. AI 프롬프트를 **5개 구조축(역관목조분)**으로 분해해 일관성 있게 설계하는 방법 제공
2. AI에 요청하는 작업을 **5개 유형(요정분생설)**으로 분류해 최적 지시 패턴을 자동 매핑하는 시스템 제공
3. 두 프레임워크를 결합한 **통합 인터페이스**를 통해 비전문가도 고품질 프롬프트를 생성하는 환경 제공
4. 생성된 프롬프트를 **조직 단위로 저장·공유·재사용**할 수 있는 라이브러리 시스템 제공

---

## 6. 발명의 구성 (핵심 기술 내용)

### 6.1 역관목조분 — 5축 프롬프트 구조 분해 프레임워크

본 발명의 제1 구성 요소로서 "역관목조분(役關目條分)"은 AI 프롬프트를 구성하는 5개의 필수 설계 축을 정의한다:

| 축 | 한자 의미 | 프롬프트 요소 | 예시 |
|----|-----------|--------------|------|
| 역(役) | 역할 | 누가 답하는가 | "농협경제지주 정책 커뮤니케이션 담당자" |
| 관(關) | 관련분야 | 어떤 영역의 지식 | "농산물 유통 정책, 조합원 커뮤니케이션" |
| 목(目) | 목적 | 왜 답하는가 | "조합원 대상 카드뉴스 제작" |
| 조(條) | 조건 | 제약·형식·근거 | "각 카드 30자 이내, 60대 이해 가능 수준" |
| 분(分) | 분량 | 길이·분량·형식 | "카드 4장, 장당 본문 3줄" |

5개 축이 모두 명시된 프롬프트와 그렇지 않은 프롬프트의 AI 응답 품질 차이를 실험적으로 검증하였으며, 모든 축을 포함할 때 일관적 고품질 출력이 달성된다.

### 6.2 요정분생설 — 5종 AI 작업 유형 분류 체계

본 발명의 제2 구성 요소로서 "요정분생설(要精分生說)"은 AI에 요청하는 작업을 5가지 유형으로 분류한다:

| 유형 | 한자 의미 | 설명 | 최적 프롬프트 패턴 |
|------|-----------|------|------------------|
| 요(要) | 요약 | 긴 내용을 핵심만 추출 | 출력 길이 제한 + 핵심 기준 명시 |
| 정(精) | 정리 | 분산된 정보를 체계화 | 분류 기준 + 위계 구조 명시 |
| 분(分) | 분석 | 데이터·텍스트를 해석 | 분석 관점 + 근거 요구 명시 |
| 생(生) | 생성 | 새로운 콘텐츠 창작 | 형식·어조·독자 층 명시 |
| 설(說) | 설명 | 개념·과정을 쉽게 서술 | 청중 수준 + 예시 포함 여부 명시 |

### 6.3 통합 프롬프트 자동 조립 알고리즘

사용자가 UI에서 역관목조분 5축 값과 요정분생설 유형을 입력하면, 시스템은 다음 알고리즘으로 최적화된 프롬프트를 자동 생성한다:

```
입력: {역할, 관련분야, 목적, 조건, 분량, 작업유형, 본문}

처리:
1. 작업유형에 따른 도입부 패턴 선택
   - 요약: "[유형] 요약\n[역할] {역할}\n..."
   - 생성: "[유형] 생성\n[역할] {역할}\n..."
   (각 유형별 최적 어순·강조 방식 상이)

2. 비어있는 축은 자동 생략 (잡음 방지)

3. 역할·목적·조건이 모두 있을 때 
   "당신은 {역할}입니다. {목적}을 위해..." 형태로 자연어 통합

출력: 구조화된 프롬프트 텍스트
```

### 6.4 조직별 프롬프트 라이브러리 시스템

생성된 프롬프트를 다음 세 가지 스코프로 저장·공유한다:
- **개인 전용**: 본인만 접근
- **조직 공유**: 같은 조직(회사/기관) 구성원 공유
- **전체 공개**: 플랫폼 전체 사용자 공유

각 프롬프트에는 역관목조분 5축 메타데이터와 요정분생설 유형이 태그로 저장되어, 검색·필터링이 가능하다.

---

## 7. 발명의 효과

1. **일관성 향상**: 동일 업무에 대해 다른 사용자가 입력해도 유사한 품질의 결과 획득
2. **진입 장벽 감소**: 프롬프트 엔지니어링 전문 지식 없이도 고품질 AI 결과물 생성 가능
3. **한국어 공문서 특화**: 한국 행정·업무 환경(농협, 공공기관 등)에 최적화된 어조·형식 자동 반영
4. **조직 지식 자산화**: 개인의 프롬프트 노하우를 조직 공유 자산으로 축적
5. **재사용률 향상**: 구조화된 메타데이터로 유사 업무 프롬프트 즉시 검색·재활용

---

## 8. 청구항 아이디어 (변리사 검토용)

**독립 청구항 후보:**

1. AI 프롬프트를 역할(役)·관련분야(關)·목적(目)·조건(條)·분량(分)의 5개 축으로 구조화하고, 요약·정리·분석·생성·설명 중 하나의 작업 유형과 결합하여 최적화된 프롬프트 텍스트를 자동 생성하는 방법

2. 위 방법을 수행하는 컴퓨터 프로그램 및 서버 시스템

3. 역관목조분 5축 메타데이터가 부착된 프롬프트를 조직 단위로 저장·검색·공유하는 라이브러리 관리 시스템

**종속 청구항 후보:**

- 비어 있는 축을 자동 감지해 프롬프트에서 생략하는 단계를 포함하는 청구항 1의 방법
- 조직 공개/개인 전용 스코프 선택 단계를 포함하는 청구항 3의 시스템
- 한국어 공문서 어조(높임말, 공식체) 자동 적용 단계를 포함하는 청구항 1의 방법
