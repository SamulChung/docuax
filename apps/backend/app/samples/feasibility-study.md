# 사업타당성 분석 보고서 — 일본 시장 진출 검토

**검토대상:** 일본어 모델 개발 및 일본 시장 진출
**검토기간:** 2026년 2월 ~ 3월 (6주)
**작성:** 전략기획팀 / 외부 자문 (○○컨설팅)
**보고:** 경영진 / 이사회

## Ⅰ. 검토 배경

### 1. 검토 필요성

본 사는 한국 시장에서 매크로 100종 + 한국어 특화 LLM 기반 문서 자동화 SaaS를 안정화하고 있으며, 2028년 ARR 75억 달성 후 다음 성장 동력으로 일본 시장 진출을 검토하고 있다.

| 항목 | 내용 |
| --- | --- |
| 검토 시점 | 2026년 2월 |
| 의사결정 시한 | 2026년 Q3 |
| 진출 시점 (계획) | 2028년 Q1 |
| 검토 범위 | 시장성·기술성·재무성·법적 타당성 |

### 2. 검토 방법론

  ○ 데스크리서치: 일본 시장 보고서 12건, 정부 자료 8건
  ○ 현지 인터뷰: 도쿄·오사카 12개사 IT·총무 담당
  ○ 전문가 자문: 일본 진출 경험 IT 기업 3사, 일본 법무법인 1곳
  ○ 재무 모델링: 5년 손익·자금 시뮬레이션

  ○ 2025년 시장 규모: 약 1,200억엔 (한화 약 1조 800억원, 한국 시장의 4.5배)

### 2. 추진 조건

본사가 일본 진출을 추진하기 위해 다음 4개 조건이 충족되어야 한다.

  1. **한국 ARR 50억 달성** (2027 Q2) — 한국 자생 확보 후 진출
  2. **시리즈 A 또는 B로 추가 자금 80억원 확보** — 일본 진출 자금
  3. **한·일 듀얼 모델 PoC 성공** (2027 Q1) — 기술 검증
  4. **일본 현지 파트너 1개사 MOU** (2027 Q3) — 영업 채널 확보
