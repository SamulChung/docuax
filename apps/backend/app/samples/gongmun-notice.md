## 제목

**2026년 상반기 전사 워크숍 개최 안내 및 참가 신청 협조**

## 본문

### 1. 행사 취지

  가. 평소 회사 발전을 위해 헌신해 주시는 임직원 여러분께 깊이 감사드립니다.

  나. 2026년 상반기를 마무리하고 하반기 도약의 발판을 마련하고자, 다음과 같이 전사 워크숍을 개최하오니 적극적인 참여를 부탁드립니다.

  다. 이번 워크숍은 (1) 상반기 성과 회고, (2) 하반기 OKR 설정, (3) 시리즈 A 종결 기념 등 3대 주제로 진행되며, 부서 간 교류를 활성화하는 시간으로 마련됩니다.

### 2. 행사 개요

```
┌─────────────────────────────────────────────────────────┐
│  일시:   2026년 6월 14일(금) 10:00 ~ 18:00              │
│  장소:   강원도 ○○ 컨퍼런스홀 (지상 3층)      │
│  참석:   전 직원 (재택근무자·외근자 포함)              │
│  주제:   상반기 회고 + 하반기 OKR + 시리즈A 기념        │
│  복장:   비즈니스 캐주얼                                │
└─────────────────────────────────────────────────────────┘
```

### 4. 참가 신청

  가. **사전 신청 마감:** 2026년 6월 5일(금) 17:00까지
  나. **신청 방법:** 인트라넷 → "행사 신청" → "2026 상반기 워크숍" 클릭
  다. **신청 시 입력 사항:**
    ─ 만찬 참석 여부 (예/아니오)
    ─ 식이 제한 사항 (채식·할랄·견과류 알레르기 등)
    ─ 교통편 (전세버스 / 개인 차량)
    ─ 룸메이트 희망자 (1박 희망 시)

### 5. 교통편 안내

  가. **전세버스 (회사 제공)**
    ─ 출발: 6.14(금) 09:00 본사 정문
    ─ 도착: 6.14(금) 20:30 본사 정문
    ─ 정원: 90명 (2대)

  나. **개인 차량**
    ─ 주차 무료 (호텔 지상·지하 주차장)
    ─ 카풀 게시판 운영 (인트라넷 → 행사 신청 → 카풀)

  다. **1박 희망자 (자비)**
    ─ 호텔 단체 할인가: 1인 12만원 (조식 포함)
    ─ 신청 마감: 6.5(금) 17:00 — 인사총무팀 직접 신청
