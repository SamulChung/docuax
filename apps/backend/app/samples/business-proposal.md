## Ⅰ. 사업 배경 및 필요성

### 1. 시 단위 공공문서 작성의 현실

  가. ○○○○ (수요기관) 본청·산하기관 종사자 약 1,420명이 연간 약 22만건의 보고서·공문을 작성
  나. 1건당 평균 작성 시간 3.2시간 → 연간 환산 약 70.4만 시간 (350명 정원 환산)
  다. 양식 불일치·결재 반려율 평균 18% — 재작성 부담 가중
  라. 외산 LLM(글로벌 LLM 등)은 망분리 환경에서 사용 불가, 한컴 호환 부재

### 2. 본 사업의 필요성

  ※ **외산 AI는 한국 공문 양식·HWP·망분리 환경에 모두 부적합하다.**
  ※ 한국어 특화 LLM + 매크로 100종 + 망분리 온프레미스가 동시에 필요한 시점.

### 3. 정책적 근거

  ○ 「공공기관 망분리 환경 AI 활용 가이드라인」(○○부처, 2025.9)
  ○ 「2026 디지털전환 시행계획」(관계부처, 2026.1)
  ○ ○○○○ (지역) 「디지털전환 4개년 기본계획」(2025.11 시의회 의결)

## Ⅱ. 본사 솔루션 소개 — ○○○○○

### 1. 제품 한 줄 소개

> **마크다운을 한 번에 한국 회사 문서(HWP·DOCX·PDF)로 — 매크로 100종 + 한국어 LLM 자체 두뇌**

### 2. 핵심 차별점

| 차별점 | 본사 | 글로벌 LLM | 국내 경쟁사 |
| --- | :---: | :---: | :---: |
| 한국어 자체 LLM 28B 모델 | ✓ | ─ | △ (소형만) |
| 매크로 100종 | ✓ | ─ | ─ |
| 한컴 한글 HWPX 정식 호환 | ✓ | ─ | △ |
| 망분리 온프레미스 | ✓ | ─ | △ |
| ISMS-P 인증 | ✓ (2026 6월) | △ | △ |
| 한국 4단계 글머리 인식 | ✓ | ─ | △ |
| 두뇌(모델) 교체 자유 | ✓ | ─ | ─ |

### 3. 핵심 기능

  ○ **변환 엔진** — 마크다운/Word 입력 → 표준 양식 DOCX·HWPX·PDF 출력
  ○ **매크로 100종** — 표(T) 25 + 표세부(S) 15 + 블록(B) 20 + 글자(G) 15 + 이동(N) 10 + 검토(R) 10 + 편리(P) 5
  ○ **검토 시스템** — 빨강(환각 의심)·파랑(키워드)·노랑(수치·일자) 자동 표시
  ○ **조직 양식 프로파일** — 시청 표준 양식·브랜드 색·서체 자동 적용
  ○ **감사 로그** — 모든 변환·매크로 실행 90일 보관, ISMS-P 대응

  ○ **운영 방식:** 일일 사용 + 주간 사용 현황 보고 + 월간 개선 회의
  ○ **사용 영역:** 보고서·공문·결재서·회의록 작성
  ○ **개선 KPI:** 평균 작성 시간, 양식 일치도, 결재 반려율

  ○ **확산 범위:** 본청 23개 부서 + 산하기관 12개소 (총 1,420명)
  ○ **교육 일정:** 입문 교육 4회 + 심화 교육 4회 (총 8회, 약 2,000명 누적 수강)
  ○ **운영지원:** 24시간 기술지원 (이메일·전화·온사이트)
  ○ **성과 측정:** 정량(시간·건수·오류율) + 정성(만족도) 측정
