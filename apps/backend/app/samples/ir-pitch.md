## Ⅱ. 문제 — 우리가 해결하는 통점

※ **한국 기업·기관의 문서 작성은 여전히 손으로 한다.**

□ **현실 1: 글로벌 LLM은 한국 양식을 모른다**
  ○ 글로벌 LLM은 한국 공문 4단계 글머리(□ ○ ― ※)를 제대로 못 씀
  ○ HWP(한컴 한글) 파일 정식 호환 LLM은 **사실상 없음**
  ○ 한국 양식 정확도 평균 47% (자체 측정, 100건 표본)

□ **현실 2: 망분리 환경에서 외부 LLM 사용 불가**
  ○ 공공기관 망분리 적용률 82%, 금융권은 100%
  ○ "외부 LLM 자료 유출"이 가장 큰 두려움
  ○ 결과: 가장 큰 시장인 공공·금융은 글로벌 LLM에 접근 불가

□ **현실 3: 기존 매크로·RPA로는 비정형 처리 불가**
  ○ 한컴 자체 매크로는 LLM이 없음
  ○ RPA는 입력 형식이 고정된 경우만 동작

## Ⅲ. 해결 — DocuAX

### 1. 한 줄 가치 제안

> **"마크다운을 입력하면, 회사 표준 양식의 DOCX/HWPX/PDF가 한 번에 나옵니다."**

### 2. 핵심 기술 — 2계층 분리 (Brain-Arms)

```
┌──────────────────────────────────────────────┐
│  DocuAX (팔: 실행)                            │
│  • 매크로 100종                              │
│  • 한국 양식 매핑                            │
│  • DOCX/HWPX/PDF 직렬화                      │
│  • 조직별 브랜드 적용                        │
└────────────────────┬─────────────────────────┘
                     │
                     ▼  ModelProvider 인터페이스
┌──────────────────────────────────────────────┐
│  자체 LLM (두뇌)                                │
│  • 한국어 특화 LLM 자체 모델                    │
│  • 한국어 KLUE 79.8 (동급 1위)               │
│  • 외부 API 폴백 (글로벌 LLM A, 글로벌 LLM B)         │
│  • 망분리 환경 자체 호스팅                   │
└──────────────────────────────────────────────┘
```

> **차별점:** 두뇌(모델)를 자유롭게 교체할 수 있어, 차세대 글로벌 LLM A/차세대 글로벌 LLM B 등 차세대 모델 출시 시에도 본사 가치가 보존됨.

### 3. 매크로 100종 — 글로벌 미보유

| 카테고리 | 개수 | 예시 |
| --- | ---: | --- |
| 표 (T) | 25 | 표 자동 생성, 셀 병합, 통계 요약 |
| 표세부 (S) | 15 | 폭 균등, 헤더 강조, 조건부 셀 색 |

| 편리 (P) | 5 | 일괄 적용, 매크로 체인 |
| **합계** | **100** | **35종 AI 강화** |
