## Ⅰ. 연구 개요

### 1. 연구 목표

본 과제는 한국 기업·기관의 표준 문서(공문·보고서·제안서·회의록 등) 작성에 필요한 100종 매크로를 한국어 특화 LLM 위에서 실용 수준으로 구현하는 것을 목표로 한다.

| 구분 | 목표 | 달성 결과 |
| --- | --- | --- |
| 매크로 개수 | 100종 | 100종 ✓ |
| 평균 응답 지연 | 800ms 이하 | 612ms ✓ |
| 정확도 (R3 검토) | 88% 이상 | 91.4% ✓ |
| 한컴 양식 호환률 | 95% 이상 | 97.2% ✓ |
| 학습 토큰 효율 | 영문 대비 80% | 84.3% ✓ |

### 2. 연구 배경

□ **기술적 필요성**
  ○ 글로벌 LLM(글로벌 LLM 등)은 한국 공문 글머리(□ ○ ― ※)·HWP 양식·결재선 등 한국 행정 표준에 취약
  ○ 매크로 100종을 통해 LLM 출력을 표준 양식에 맞게 후처리

□ **시장 수요**
  ○ 공공기관 망분리 환경 → 자체 호스팅 LLM + 매크로 필요
  ○ 컨설팅 인터뷰 23회 결과 87% "한국 양식 자동화가 가장 필요"

## Ⅱ. 연구 내용 및 방법

### 1. 매크로 카테고리 설계

```
┌────────────────────────────────────────────────────────┐
│  100종 매크로 = 표(T) + 표세부(S) + 블록(B) + 글자(G) │
│                + 이동(N) + 검토(R) + 편리(P)          │
└────────────────────────────────────────────────────────┘
```

| 카테고리 | 코드 | 개수 | AI 강화 |
| --- | --- | ---: | ---: |
| 표 매크로 | T1~T25 | 25 | 8 |
| 표세부 매크로 | S1~S15 | 15 | 5 |
| 블록 매크로 | B1~B20 | 20 | 3 |
| 글자 매크로 | G1~G15 | 15 | 2 |
| 이동 매크로 | N1~N10 | 10 | 5 |
| 검토 매크로 | R1~R10 | 10 | 10 |
| 편리 매크로 | P1~P5 | 5 | 2 |
| **합계** | | **100** | **35** |

### 2. 한국어 특화 LLM 모델 설계

□ **베이스 모델**
  ○ 오픈소스 LLM → 28B 증류(Distillation)
  ○ 한국어 토큰 효율 +37% 개선 (BPE 한글 음절 우선 분할)

□ **사전학습 데이터**
  ○ 한국 공공문서 (정책정보포털) 12억 토큰
  ○ 학술논문 (KCI 검색) 8.4억 토큰
  ○ 법령·판례 (국가법령정보센터) 3.1억 토큰
  ○ 기업 IR 자료 (DART 공시) 5.7억 토큰
  ○ 합계: 29.2억 토큰 (한국어 비율 92%)

□ **파인튜닝**
  ○ SFT: 매크로별 입출력 쌍 12,400 건
  ○ DPO: 한국 공문 양식 선호도 학습 (3,200 페어)
  ○ 최종 모델: 한국어 특화 LLM (v1.2)
